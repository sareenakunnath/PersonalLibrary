# Personal Library

A Django web application to manage a personal book collection

## Features

- User Registration
- User Login & Logout
- Add Books
- Edit Books
- Delete Books
- View Books
- Book Categories
- Responsive Navigation Bar

- Python 
- Django
- HTML
- CSS
- Bootstrap
- SQLite
